# Инструкция по применению миграций для гибкого управления назначениями

## Описание изменений

Реализована система гибкого управления назначениями курсов и траекторий. Теперь при ручной отмене назначения через интерфейс управления пользователями, курс или траектория не будут автоматически переназначены обратно, даже если пользователь состоит в группе с этим обучением.

## Что было добавлено

### 1. Новые модели
- **`ManualCourseUnassignment`** - отслеживает ручные отмены назначений курсов
- **`ManualTrajectoryUnassignment`** - отслеживает ручные отмены назначений траекторий

### 2. Обновлённые функции
- View-функции отмены назначений теперь создают записи в новых моделях
- Все сигналы автоматического назначения проверяют наличие ручных отмен

### 3. Админ-панель
- Добавлены разделы для управления ручными отменами в Django Admin

## Применение миграций

### Шаг 1: Создание миграций
```bash
cd /opt/pearls-site-django
python manage.py makemigrations myapp
python manage.py makemigrations courses
```

### Шаг 2: Проверка миграций
```bash
python manage.py showmigrations myapp
python manage.py showmigrations courses
```

### Шаг 3: Применение миграций
```bash
python manage.py migrate myapp
python manage.py migrate courses
```

### Шаг 4: Проверка
После применения миграций проверьте:
1. В админ-панели появились новые разделы для ручных отмен
2. При отмене назначения курса/траектории через интерфейс, они больше не переназначаются автоматически

## Как работает система

1. **Отмена назначения**: При клике на крестик в интерфейсе управления пользователями:
   - Удаляется запись `UserCourse` или `UserCourseTrajectory`
   - Создаётся запись `ManualCourseUnassignment` или `ManualTrajectoryUnassignment`
   - Запись содержит информацию о том, кто и когда отменил назначение

2. **Проверка при автоназначении**: Все сигналы автоматического назначения (при добавлении пользователя в группу, добавлении курса в группу и т.д.) теперь проверяют наличие записей о ручных отменах и пропускают назначение, если такая запись существует.

3. **Логирование**: Все действия логируются в журнал аудита с подробной информацией.

## Управление через админ-панель

Администратор может:
- Просматривать все ручные отмены
- Удалять записи о ручных отменах (это позволит системе снова автоматически назначать курсы/траектории)
- Фильтровать и искать по пользователям и курсам/траекториям

## Примечания

- Записи о ручных отменах не удаляются автоматически
- Если нужно вернуть автоматическое назначение для конкретного пользователя и курса, удалите соответствующую запись в админ-панели
- Все изменения логируются для аудита
