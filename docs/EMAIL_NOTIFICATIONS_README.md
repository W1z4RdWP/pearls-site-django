# Email уведомления для назначения курсов и траекторий

## Что реализовано

Система автоматической отправки email уведомлений при назначении курсов и траекторий пользователям.

### 1. Функции отправки email
**Файл:** `myproject/apps/user_management/utils.py`

- `send_course_assignment_email(user, course)` - отправка уведомления о назначении курса
- `send_trajectory_assignment_email(user, trajectory)` - отправка уведомления о назначении траектории

### 2. HTML шаблоны писем
**Шаблоны:**
- `myproject/apps/user_management/templates/user_management/email/course_assignment.html`
- `myproject/apps/user_management/templates/user_management/email/trajectory_assignment.html`

**Особенности шаблонов:**
- Современный дизайн с градиентами и стилизацией
- Кнопка "Пройти курс" / "Начать обучение" ведущая к курсу/траектории
- Адаптивная верстка
- Резервные ссылки для копирования

### 3. Интеграция с сигналами
**Файл:** `myproject/apps/courses/signals.py`

Email уведомления отправляются автоматически при:
- Добавлении пользователя в группу (если у группы есть курсы/траектории)
- Добавлении группы к курсу (всем пользователям группы)
- Добавлении группы к траектории (всем пользователям группы)
- Добавлении курса в траекторию (всем пользователям траектории)

### 4. Интеграция с системой уведомлений
**Файл:** `myproject/apps/notifications/models.py`

Email отправляется дублированно при создании системных уведомлений через:
- `Notification.create_course_assignment_notification()`
- `Notification.create_trajectory_assignment_notification()`

## Как тестировать

### 1. Настройка email
Убедитесь, что в `.env` настроены параметры SMTP:
```env
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=true
EMAIL_HOST_USER=your-email@gmail.com
EMAIL_HOST_PASSWORD=your-app-password
```

### 2. Тестирование назначения курса
1. Создайте курс в админке
2. Создайте группу и добавьте к ней курс
3. Добавьте пользователя в эту группу
4. Проверьте email пользователя - должно прийти уведомление

### 3. Тестирование назначения траектории
1. Создайте траекторию в админке
2. Добавьте курсы в траекторию
3. Создайте группу и добавьте к ней траекторию
4. Добавьте пользователя в эту группу
5. Проверьте email пользователя - должно прийти уведомление

### 4. Структура email для курса
- **Заголовок:** "Вам назначен курс: [Название курса]"
- **Содержание:** Приветствие, информация о курсе, кнопка "🚀 Пройти курс"
- **Ссылка:** Ведет на страницу курса

### 5. Структура email для траектории
- **Заголовок:** "Вам назначена траектория обучения: [Название]"
- **Содержание:** Приветствие, информация о траектории, список преимуществ
- **Кнопки:** "🚀 Начать обучение" (первый курс) и "📋 Посмотреть траекторию"

## Логирование

Все действия по отправке email логируются:
- Успешная отправка: INFO уровень
- Ошибки отправки: ERROR уровень

Логи можно найти в стандартном логе Django или настроить отдельный файл для email уведомлений.

## Возможные ошибки и решения

1. **Email не отправляется:** Проверьте настройки SMTP в `.env`
2. **Ошибка импорта:** Убедитесь, что app `user_management` добавлен в `INSTALLED_APPS`
3. **Ошибка шаблона:** Проверьте пути к шаблонам в `TEMPLATES` настройках
4. **Неправильные URL:** Убедитесь, что `SITE_URL` в настройках корректный
5. **HTML не отображается (видны теги):** 
   - Используется `EmailMultiAlternatives` вместо обычного `send_mail`
   - Все стили встроены inline для совместимости с email клиентами
   - Простая структура HTML без сложных CSS

## Логика работы уведомлений

### При назначении траектории:
1. Создается `UserCourseTrajectory`
2. Назначаются все курсы из траектории БЕЗ email уведомлений и БЕЗ внутренних уведомлений
3. Создается ОДНО внутреннее уведомление о траектории
4. Отправляется ОДНО email уведомление о траектории

### При назначении отдельного курса:
1. Создается `UserCourse`
2. Создается внутреннее уведомление о курсе
3. Отправляется email уведомление о курсе

Это исключает дублирование email при назначении траекторий.
