# Документация: Многоуровневая оценка открытых вопросов в тестах

## Обзор

Реализована система многоуровневой оценки открытых вопросов (TEXT) в тестах с возможностью оценки наставником/администратором.

## Основные изменения

### 1. Модели

#### QuizResult (myproject/apps/myapp/models.py)
Новые поля:
- `status` - статус теста ('pending' - ожидает проверки, 'completed' - завершен)
- `reviewed_by` - наставник/администратор, проверивший тест
- `reviewed_at` - дата и время проверки
- `mentor_comment` - комментарий наставника

#### UserAnswer (myproject/apps/myapp/models.py)
Новые поля:
- `score_points` - баллы за ответ (0, 0.5, 1) для многоуровневой оценки

### 2. Логика работы

#### При завершении теста (get_finish):
- Если тест содержит открытые вопросы (TEXT), он получает статус 'pending'
- Тест не считается пройденным до проверки наставником
- Студент видит уведомление о том, что тест отправлен на проверку
- Предварительные результаты по автопроверяемым вопросам отображаются

#### Система оценки открытых вопросов:
- **0 баллов** - неверно
- **0.5 балла** - частично верно
- **1 балл** - верно

#### После оценки наставником:
- Пересчитывается общий балл теста с учетом оценок открытых вопросов
- Определяется, прошел ли студент тест на основе проходного балла
- Начисляются DASCOIN и выдаются сертификаты (если применимо)
- Статус теста меняется на 'completed'

### 3. Интерфейс для наставников

#### Доступ:
- URL: `/quizzes/pending/` - список тестов на проверку
- URL: `/quizzes/review/<result_id>/` - страница оценки конкретного теста
- Доступ только для пользователей со статусом `is_staff`

#### Функционал:
- Просмотр всех тестов со статусом 'pending'
- Просмотр ответов студента на открытые вопросы
- Оценка каждого открытого вопроса (0 / 0.5 / 1 балл)
- Добавление комментария наставника
- Автоматический пересчет результата теста

#### Админ-панель:
- В списке результатов тестов добавлена колонка со ссылкой "Оценить"
- Фильтрация по статусу (pending/completed)
- Отображение наставника, проверившего тест

### 4. Интерфейс для студентов

#### После завершения теста с открытыми вопросами:
- Отображается уведомление: "⏳ Тест отправлен на проверку"
- Показываются предварительные результаты по автопроверяемым вопросам (если есть)
- Студент информируется, что результаты будут доступны после проверки

## Использование

### Для наставников:

1. **Просмотр тестов на проверку:**
   - Перейти по адресу `/quizzes/pending/`
   - Или через админ-панель Django → "Результаты тестов" → фильтр по статусу "Ожидает проверки"

2. **Оценка теста:**
   - Нажать кнопку "Оценить" напротив теста
   - Просмотреть ответы студента на открытые вопросы
   - Выбрать оценку для каждого вопроса:
     * ❌ Неверно (0 баллов)
     * ⚠️ Частично верно (0.5 балла)
     * ✅ Верно (1 балл)
   - При необходимости добавить комментарий
   - Нажать "Сохранить оценку"

3. **После сохранения:**
   - Тест автоматически получает статус 'completed'
   - Пересчитывается итоговый результат
   - Начисляются баллы и выдаются сертификаты (если применимо)

### Для студентов:

1. **Прохождение теста:**
   - Пройти тест как обычно
   - На открытые вопросы ответить в текстовом поле

2. **После завершения:**
   - Если тест содержит открытые вопросы:
     * Увидеть уведомление об отправке на проверку
     * Дождаться оценки наставником
   - Если тест не содержит открытых вопросов:
     * Увидеть результаты сразу

## Примеры использования

### Пример 1: Тест только с открытыми вопросами
- Студент проходит тест с 5 открытыми вопросами
- После завершения тест получает статус 'pending'
- Наставник оценивает ответы: 1 + 0.5 + 1 + 0.5 + 1 = 4 балла из 5
- Процент: 80%
- Если проходной балл 70%, тест считается пройденным

### Пример 2: Смешанный тест
- Тест содержит 5 автопроверяемых вопросов и 3 открытых
- Студент правильно ответил на 4 автопроверяемых вопроса
- Тест получает статус 'pending'
- Наставник оценивает открытые вопросы: 1 + 0.5 + 1 = 2.5 балла из 3
- Итого: 4 + 2.5 = 6.5 баллов из 8
- Процент: 81%

## Важные замечания

1. Тесты с открытыми вопросами НЕ считаются пройденными до проверки наставником
2. DASCOIN и сертификаты НЕ начисляются до оценки наставником
3. При запуске теста из панели управления администратором (`from_control_panel`), проверка и начисление баллов не происходит
4. Наставник может оставить комментарий к результату теста
5. Все ответы студента (включая автопроверяемые) отображаются наставнику для справки
