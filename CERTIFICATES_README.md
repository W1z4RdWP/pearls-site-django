# Система сертификатов

## Описание
Система автоматической выдачи сертификатов пользователям при завершении курсов и траекторий.

## Возможности

### 1. Настройка выдачи сертификатов
- **Курсы**: При создании/редактировании курса доступна галочка "Выдавать сертификат"
- **Траектории**: При создании/редактировании траектории доступна галочка "Выдавать сертификат"

### 2. Автоматическая выдача
Сертификаты выдаются автоматически при:
- Завершении курса (если включена опция "Сертификат")
- Завершении траектории (если включена опция "Сертификат")

### 3. Уникальность
- Каждый сертификат имеет уникальный номер формата `CERT-XXXXXXXXXXXX`
- Пользователь не может получить несколько сертификатов за один курс/траекторию

## Где настраивать

### Курсы
1. Перейти в админку Django → Courses → Courses
2. При создании/редактировании курса поставить галочку "Выдавать сертификат"
3. Или использовать форму создания курса на сайте `/create-course/`

### Траектории  
1. Перейти в админку Django → Courses → Trajectories
2. При создании/редактировании траектории поставить галочку "Выдавать сертификат"
3. Или использовать форму создания траектории на сайте `/trajectory-create/`

## Просмотр сертификатов

### Для пользователей
- URL: `/user-certificates/`
- Отображает все сертификаты пользователя, разделенные по типам
- Возможность скачать каждый сертификат в формате PDF

### Для администраторов
- Админка Django → Courses → Certificates
- Просмотр всех выданных сертификатов
- Поиск по пользователям, номерам сертификатов

## Техническая информация

### Модели
- `Course.certificate` - BooleanField, включает/отключает выдачу сертификатов
- `Trajectory.certificate` - BooleanField, включает/отключает выдачу сертификатов  
- `Certificate` - модель для хранения выданных сертификатов

### API функции
- `issue_certificate(user, course=None, trajectory=None)` - выдача сертификата
- `get_user_certificates(user)` - получение всех сертификатов пользователя
- `download_certificate_pdf(request, certificate_id)` - скачивание сертификата в PDF

### PDF генерация
- Используется библиотека **WeasyPrint** (та же, что и для отчетов DASCOIN)
- Красивый дизайн сертификата с градиентами и декоративными элементами
- Автоматическое формирование имени файла

### Логирование
Все операции выдачи сертификатов логируются в стандартный logger Django.

## Интеграция

Система автоматически интегрирована в существующие процессы завершения курсов и траекторий:
- `courses/views.py` - завершение курсов
- `quizzes/views.py` - завершение через тесты
- Автоматическое завершение траекторий

## База данных

### Таблица certificates_certificate
- `id` - первичный ключ
- `user_id` - пользователь
- `certificate_type` - тип ('course' или 'trajectory')
- `course_id` - курс (если тип 'course')
- `trajectory_id` - траектория (если тип 'trajectory')
- `issued_at` - дата выдачи
- `certificate_id` - уникальный номер сертификата

### Индексы
- По пользователю и типу сертификата
- По номеру сертификата
- Уникальность: (пользователь, курс) и (пользователь, траектория)
