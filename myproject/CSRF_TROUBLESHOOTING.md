# Решение проблем с CSRF при авторизации

## Проблема
При попытке авторизации возникает ошибка:
```
Ошибка доступа (403)
Ошибка проверки CSRF. Запрос отклонён.
CSRF token from POST incorrect.
```

## Причины и решения

### 1. Проблема с HTTPS/SSL
**Причина:** `CSRF_COOKIE_SECURE = True` требует HTTPS соединения.

**Решение:**
- Убедитесь, что сайт работает по HTTPS
- Если тестируете локально, временно установите `CSRF_COOKIE_SECURE = False`

### 2. Проблема с доменами
**Причина:** `CSRF_TRUSTED_ORIGINS` не содержит нужный домен.

**Решение:**
Добавьте все возможные домены в `CSRF_TRUSTED_ORIGINS`:
```python
CSRF_TRUSTED_ORIGINS = [
    'https://lc.smileterritory.ru',
    'https://www.lc.smileterritory.ru',
    'http://lc.smileterritory.ru',  # Для тестирования
    'http://localhost:8000',  # Для локальной разработки
]
```

### 3. Проблема с cookies
**Причина:** Браузер блокирует или не сохраняет CSRF cookies.

**Решение:**
- Очистите cookies сайта в браузере
- Проверьте настройки приватности браузера
- Убедитесь, что JavaScript включен

### 4. Проблема с прокси/балансировщиком
**Причина:** Неправильная настройка заголовков прокси.

**Решение:**
Проверьте настройки:
```python
USE_X_FORWARDED_HOST = True
USE_X_FORWARDED_PORT = True
SECURE_PROXY_SSL_HEADER = ('HTTP_X_FORWARDED_PROTO', 'https')
```

## Диагностика

### 1. Используйте диагностическую страницу
Перейдите на `/csrf-debug/` для проверки:
- CSRF токена
- Cookies
- Настроек CSRF
- Тестирования отправки формы

### 2. Проверьте логи
Middleware `CSRFDebugMiddleware` логирует информацию о CSRF запросах в файл `/var/log/django/errors.log`.

### 3. Проверьте настройки браузера
- Включены ли cookies
- Не блокирует ли браузер JavaScript
- Нет ли расширений, блокирующих CSRF токены

## Экстренные меры

Если проблема критическая, используйте экстренные настройки:

1. Скопируйте `settings/csrf_emergency.py` в `settings/prod.py`
2. Или временно установите:
```python
CSRF_COOKIE_SECURE = False
CSRF_COOKIE_HTTPONLY = False
CSRF_COOKIE_SAMESITE = 'Lax'
```

**⚠️ ВНИМАНИЕ:** Эти настройки снижают безопасность!

## Проверка решения

1. Очистите cookies браузера
2. Обновите страницу входа
3. Попробуйте войти в систему
4. Если проблема остается, проверьте логи и диагностическую страницу

## Дополнительные настройки

В `settings/base.py` добавлены дополнительные настройки CSRF:
```python
CSRF_COOKIE_AGE = 31449600  # 1 год
CSRF_COOKIE_DOMAIN = None  # Автоматическое определение домена
CSRF_COOKIE_NAME = 'csrftoken'
CSRF_HEADER_NAME = 'HTTP_X_CSRFTOKEN'
CSRF_COOKIE_PATH = '/'
```

## Мониторинг

Для мониторинга CSRF ошибок:
1. Проверяйте логи Django
2. Используйте диагностическую страницу
3. Следите за отчетами пользователей
