# Административная панель статистики DASCOIN

## Описание

Административная панель для отслеживания статистики пользователей по баллам DASCOIN. Доступна только для пользователей с правами staff или superuser.

## Функциональность

### Основные возможности

1. **Общая статистика**
   - Общее количество пользователей
   - Общее количество баллов DASCOIN
   - Количество активных пользователей

2. **Фильтрация пользователей**
   - По группам пользователей
   - По должностям
   - По диапазону баллов (минимум/максимум)
   - Быстрые фильтры:
     - Топ-10 пользователей по баллам
     - Пользователи без баллов
     - Только подтвержденные пользователи

3. **Детальная информация о пользователях**
   - ФИО и email
   - Группы и должности
   - Количество баллов DASCOIN
   - Статус аккаунта (активен/ожидает/неактивен)
   - Дата регистрации

4. **Действия с пользователями**
   - Ссылка на детальный отчет прогресса
   - Просмотр истории транзакций конкретного пользователя

5. **Экспорт данных**
   - Экспорт в Excel
   - Экспорт в PDF

## Доступ

### URL маршруты

- **Основная панель**: `/users/admin/dashboard/`
- **Экспорт Excel**: `/users/admin/stats/export/excel/`
- **Экспорт PDF**: `/users/admin/stats/export/pdf/`
- **Транзакции пользователя**: `/users/admin/user/<user_id>/transactions/`
- **Экспорт транзакций Excel**: `/users/admin/user/<user_id>/transactions/export/excel/`
- **Экспорт транзакций PDF**: `/users/admin/user/<user_id>/transactions/export/pdf/`

### Права доступа

Доступ к панели имеют только пользователи с правами:
- `is_staff = True` или
- `is_superuser = True`

## Использование

### Навигация

Панель доступна через главное меню для staff пользователей:
- Иконка: `fa-chart-line`
- Название: "Статистика DASCOIN"

### Фильтрация

1. **Основные фильтры** (форма в верхней части):
   - Выберите группу из выпадающего списка
   - Выберите должность из выпадающего списка
   - Укажите минимальное количество баллов
   - Укажите максимальное количество баллов
   - Нажмите "Фильтр"

2. **Быстрые фильтры** (кнопки под формой):
   - "Все пользователи" - сброс фильтров
   - "Топ-10 по баллам" - показывает 10 пользователей с наибольшим количеством баллов
   - "Без баллов" - показывает пользователей с 0 баллами
   - "Подтвержденные" - показывает только подтвержденных пользователей

### Просмотр транзакций пользователей

1. **Доступ к транзакциям**:
   - Нажмите кнопку "История транзакций" напротив любого пользователя
   - Откроется страница с транзакциями именно этого пользователя
   - Показывается информация о пользователе (ФИО, email, группы, должность, статус)

2. **Фильтрация транзакций**:
   - Фильтр по типу транзакции (начисление, списание, установка, корректировка)
   - Статистика по типам транзакций
   - Пагинация для больших списков

3. **Экспорт транзакций**:
   - Excel экспорт с именем `transactions_<username>_YYYYMMDD_HHMM.xlsx`
   - PDF экспорт с именем `transactions_<username>_YYYYMMDD_HHMM.pdf`
   - Экспорт учитывает примененные фильтры

### Экспорт

1. **Excel экспорт**:
   - Нажмите кнопку "Экспорт Excel"
   - Файл будет скачан с именем `admin_stats_YYYYMMDD_HHMM.xlsx`
   - Содержит все данные с примененными фильтрами

2. **PDF экспорт**:
   - Нажмите кнопку "Экспорт PDF"
   - Файл будет скачан с именем `admin_stats_YYYYMMDD_HHMM.pdf`
   - Содержит общую статистику и таблицу пользователей

### Пагинация

При большом количестве пользователей используется пагинация:
- 25 пользователей на страницу
- Навигация по страницам внизу таблицы
- Фильтры сохраняются при переходе между страницами

## Техническая реализация

### Модели

- `User` - основная модель пользователя
- `Profile` - профиль пользователя с полем `dascoin_points`
- `Group` - группы пользователей
- `Role` - должности пользователей

### Views

- `AdminDashboardView` - основная панель (CBV)
- `export_admin_stats_excel` - экспорт в Excel
- `export_admin_stats_pdf` - экспорт в PDF
- `AdminUserTransactionsView` - просмотр транзакций пользователя (CBV)
- `export_admin_user_transactions_excel` - экспорт транзакций пользователя в Excel
- `export_admin_user_transactions_pdf` - экспорт транзакций пользователя в PDF

### Шаблоны

- `admin_dashboard.html` - основная панель
- `admin_stats_pdf.html` - шаблон для PDF экспорта
- `admin_user_transactions.html` - просмотр транзакций пользователя

### Тесты

Полный набор тестов в `tests.py`:
- Проверка прав доступа
- Тестирование фильтрации
- Тестирование экспорта
- Тестирование отображения данных

## Логирование

Все действия администраторов логируются в аудит-лог:
- Просмотр панели
- Экспорт данных
- Применение фильтров

## Безопасность

1. **Проверка прав доступа** через `UserPassesTestMixin`
2. **Логирование действий** для аудита
3. **Валидация параметров** фильтрации
4. **Защита от SQL-инъекций** через Django ORM

## Расширение функциональности

### Добавление новых фильтров

1. Добавить параметр в `get_queryset()` метода `AdminDashboardView`
2. Обновить шаблон с новым полем фильтра
3. Добавить параметр в контекст `get_context_data()`

### Добавление новых экспортов

1. Создать новую view функцию
2. Добавить URL маршрут
3. Добавить кнопку в шаблон

### Добавление новых статистик

1. Обновить `get_context_data()` в `AdminDashboardView`
2. Добавить отображение в шаблон
3. Обновить PDF шаблон при необходимости
