# Система делегирования полномочий

## Описание

Полнофункциональная система для делегирования полномочий между пользователями платформы с подтверждением, историей и автоматическим завершением.

## Основные возможности

### 1. Создание делегирования
- Любой пользователь может создать делегирование своих прав другому пользователю
- Поля формы:
  - **Передающий**: Автоматически заполняется текущим пользователем
  - **Принимающий**: Выбор из списка активных пользователей
  - **Делегируемые права**: Текстовое описание прав
  - **Дата и время начала**: Когда права становятся активными
  - **Дата и время окончания**: До какого момента действуют
  - **Причина**: Отпуск, больничный, замена сотрудника (опционально)

### 2. Статусы делегирования
- **Ожидает подтверждения** - создано, но еще не принято принимающим
- **Активно** - подтверждено и действует
- **Завершено** - срок истек или завершено вручную
- **Отменено** - отменено передающим или отклонено принимающим

### 3. Интерфейс пользователя
Панель делегирования имеет три вкладки:

#### Исходящие делегирования
- Список всех делегирований, созданных текущим пользователем
- Возможность отменить делегирования со статусом "Ожидает подтверждения" или "Активно"

#### Входящие делегирования
- Список всех делегирований, где пользователь является принимающим
- Для ожидающих подтверждения: кнопки "Принять" и "Отклонить"
- Визуальное выделение ожидающих подтверждения (желтый фон)
- Бейдж с количеством ожидающих на вкладке

#### Все делегирования (только для админов)
- Полный журнал всех делегирований за последние 30 дней
- Доступно только для администраторов и staff

### 4. История
- Все делегирования сохраняются в базе данных навсегда
- В пользовательском интерфейсе отображаются только делегирования за последние 30 дней
- Администраторы имеют доступ к полной истории через Django Admin

### 5. Автоматическое завершение
Реализована management команда для автоматического завершения истекших делегирований:

```bash
# Применить изменения
python manage.py complete_expired_delegations

# Проверить, какие делегирования будут завершены (без изменений)
python manage.py complete_expired_delegations --dry-run
```

**Рекомендуется настроить cron для ежедневного запуска:**
```bash
# Добавить в crontab (запуск каждый день в 00:05)
5 0 * * * cd /opt/pearls-site-django/myproject && source ../.venv/bin/activate && python manage.py complete_expired_delegations
```

### 6. Административная панель
Полнофункциональная административная панель через Django Admin:
- Просмотр, редактирование, фильтрация делегирований
- Цветовые бейджи статусов
- Массовые действия: завершить, отменить, подтвердить от бизнес-ассистента
- Поиск по пользователям и правам
- Фильтры по статусу, дате, причине

## Установка и настройка

### 1. Применить миграции
```bash
cd /opt/pearls-site-django/myproject
source ../.venv/bin/activate
python manage.py migrate delegation
```

### 2. Убедиться, что приложение добавлено в INSTALLED_APPS
В файле `settings.py` должно быть:
```python
INSTALLED_APPS = [
    ...
    'delegation',
    ...
]
```

### 3. Убедиться, что URLs подключены
В главном `urls.py` должен быть:
```python
urlpatterns = [
    ...
    path('delegation/', include('myproject.apps.delegation.urls')),
    ...
]
```

### 4. Доступ к системе
- **Пользовательская панель**: `/delegation/`
- **Создание делегирования**: Через модальное окно на главной странице
- **Административная панель**: `/admin/delegation/delegation/`

## Безопасность

Реализованы проверки прав доступа:
- Пользователь может подтверждать только входящие делегирования
- Пользователь может отменять только свои исходящие делегирования
- Нельзя делегировать права самому себе
- Дата окончания должна быть позже даты начала
- Полный журнал доступен только администраторам

## API методов модели

### Delegation

#### Методы экземпляра:
- `confirm()` - Подтвердить делегирование (только для принимающего)
- `reject()` - Отклонить делегирование (только для принимающего)
- `cancel()` - Отменить делегирование (только для передающего)
- `is_active()` - Проверить, активно ли делегирование сейчас
- `should_be_completed()` - Проверить, должно ли быть завершено

#### Методы класса:
- `Delegation.get_active_delegations_for_user(user)` - Получить активные делегирования для пользователя
- `Delegation.get_recent_delegations(user, days=30)` - Получить делегирования за N дней

## Примеры использования

### Создание делегирования программно:
```python
from delegation.models import Delegation
from django.contrib.auth.models import User
from django.utils import timezone
from datetime import timedelta

delegator = User.objects.get(username='ivanov')
delegate = User.objects.get(username='petrov')

delegation = Delegation.objects.create(
    delegator=delegator,
    delegate=delegate,
    delegated_permissions='Право подписи документов и одобрения бюджетов до 100 000 руб.',
    start_datetime=timezone.now(),
    end_datetime=timezone.now() + timedelta(days=7),
    comment='vacation',
    status='pending'
)
```

### Подтверждение делегирования:
```python
delegation = Delegation.objects.get(id=1)
if delegation.confirm():
    print('Делегирование подтверждено')
```

### Получение активных делегирований для пользователя:
```python
active_delegations = Delegation.get_active_delegations_for_user(request.user)
for delegation in active_delegations:
    print(f'Активные права от {delegation.delegator.username}')
```
