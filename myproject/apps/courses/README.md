# Приложение Courses - Система управления курсами и траекториями обучения

## Обзор

Приложение `courses` представляет собой комплексную систему управления образовательными курсами, уроками и траекториями обучения. Оно обеспечивает создание, редактирование, прохождение и отслеживание прогресса пользователей по курсам.

## Модели данных

### Course (Курс)
Основная модель для представления образовательного курса.

**Поля:**
- `title` - Название курса (CharField, max_length=200)
- `description` - Описание курса (CKEditor5Field)
- `author` - Автор курса (ForeignKey на User)
- `created_at` - Дата создания (DateTimeField, auto_now_add=True)
- `image` - Изображение курса (ImageField)
- `slug` - URL-friendly идентификатор (SlugField, unique=True)
- `final_quiz` - Финальный тест курса (ForeignKey на Quiz)
- `allowed_groups` - Группы с доступом к курсу (ManyToManyField на Group)

**Особенности:**
- Автоматическая генерация slug из названия
- Уникальность slug с автоматическим добавлением счетчика
- Транслитерация названия для создания slug

### Lesson (Урок)
Модель для представления отдельных уроков в курсе.

**Поля:**
- `course` - Курс, к которому относится урок (ForeignKey на Course)
- `title` - Название урока (CharField, max_length=200)
- `content` - Содержимое урока (CKEditor5Field)
- `video_id` - ID видео с Rutube (CharField, max_length=100)
- `order` - Порядок урока в курсе (PositiveIntegerField)
- `category` - Категория урока (ForeignKey на CategoryName)

**Методы:**
- `get_previous_lesson()` - Получение предыдущего урока
- `get_next_lesson()` - Получение следующего урока

### Trajectory (Траектория)
Модель для группировки курсов в последовательные траектории обучения.

**Поля:**
- `name` - Название траектории (CharField, max_length=255)
- `description` - Описание траектории (TextField)
- `groups` - Группы пользователей (ManyToManyField на Group)
- `courses` - Курсы в траектории (ManyToManyField через TrajectoryCourse)

### TrajectoryCourse (Курс в траектории)
Промежуточная модель для связи траекторий и курсов с порядком.

**Поля:**
- `trajectory` - Траектория (ForeignKey на Trajectory)
- `course` - Курс (ForeignKey на Course)
- `order` - Порядок курса в траектории (PositiveIntegerField)

### UserCourseTrajectory (Траектория пользователя)
Индивидуальная траектория пользователя с прогрессом.

**Поля:**
- `user` - Пользователь (ForeignKey на User)
- `trajectory` - Траектория (ForeignKey на Trajectory)
- `current_course` - Текущий курс (ForeignKey на Course)
- `started_at` - Дата начала (DateTimeField, auto_now_add=True)
- `completed` - Завершена ли траектория (BooleanField, default=False)

### UserLessonTrajectory (Траектория уроков пользователя)
Модель для хранения индивидуальных траекторий уроков пользователя.
Используется для того, чтобы выбрать только нужные уроки в выбранном курсе, для выбранного пользователя.

**Поля:**
- `user` - Пользователь (ForeignKey на User)
- `course` - Курс (ForeignKey на Course)
- `lessons` - Уроки в траектории (ManyToManyField на Lesson)

## Модуль добавления уроков в курс

### Обзор
Модуль предоставляет современный интерфейс для выбора и добавления существующих уроков и категорий в курс. Реализован в виде модального окна с двумя панелями.

### Архитектура модуля

#### Файловая структура
```

static/courses/css/

```

#### Backend (Django Views)

**View:** `add_lesson(request, course_slug)`

**Основные функции:**

1. **get_categories_with_lessons()**
   ```python
   def get_categories_with_lessons():
       categories = CategoryName.objects.filter(parent=None).prefetch_related(
           'subcategories', 'lessons', 'mirrored_lessons__lesson'
       ).order_by('order', 'name')
   ```
   - Рекурсивно обходит дерево категорий
   - Включает уроки и зеркальные уроки
   - Оптимизирован с помощью `prefetch_related`

2. **get_all_lessons_in_category(category_id)**
   ```python
   def get_all_lessons_in_category(category_id):
       # Рекурсивно собирает все уроки из категории и подкатегорий
   ```

**Обработка POST запросов:**
- `add_selected` - добавление выбранных элементов
- `create_new` - перенаправление на создание нового урока

**Формат данных:**
- `category_123` - категория с ID 123
- `lesson_456` - урок с ID 456

#### Frontend (JavaScript)

**Основные функции:**

1. **performSearch(searchTerm)**
   - Выполняет поиск по категориям и урокам
   - Подсвечивает найденный текст
   - Показывает счетчик результатов
   - Поддерживает debouncing (300мс задержка)

2. **selectItem(element, type, id, title)**
   - Обрабатывает выбор элемента
   - Добавляет/удаляет из выбранных элементов
   - Обновляет визуальное состояние

3. **highlightText(element, searchTerm)**
   - Подсвечивает найденный текст
   - Использует регулярные выражения для безопасности

**Обработчики событий:**
- Поиск с debouncing
- Очистка поиска по Escape
- Выбор элементов по клику

- Левая панель: дерево категорий и уроков
