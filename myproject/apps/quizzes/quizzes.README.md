## Как импортировать и экспортировать тесты

### Экспорт
Для экспорта существующих тестов в фикстуру, используйте yaml формат.
Команда:
```bash
python manage.py dumpdata quizzes --format=yaml --indent=2 --output=quiz_data_export.yaml
```

где:
 - --format: формат файла вывода
 - --indent: количество пробелов для отступа в блоках yaml
 - --output: название файла вывода


### Импорт
Чтобы импортировать тесты из фикстуры используется команда:
```bash
python manage.py loaddata quiz_data.yaml
```

**Внимание!** Эта команда затрет собой все существующие тесты, прежде чем выполнять загрузку тестов из фикстуры убедитесь что вы сделали экспорт существующих тестов.
