# Система уведомлений

Система уведомлений для платформы обучения, которая позволяет пользователям получать уведомления о различных событиях.

## Возможности

- **Колокольчик с счетчиком** - отображает количество непрочитанных уведомлений
- **Выпадающий список** - показывает последние 5 непрочитанных уведомлений
- **Полный список уведомлений** - страница со всеми уведомлениями пользователя
- **Фильтрация и поиск** - по типу уведомлений и тексту
- **Автоматическое создание** - уведомления создаются автоматически при определенных событиях

## Типы уведомлений

1. **dascoin** - Начисление/списание баллов DASCOIN
2. **course_assigned** - Назначение курса
3. **trajectory_assigned** - Назначение траектории
4. **platform_update** - Обновление платформы
5. **course_reminder** - Напоминание о курсе
6. **lesson_actualization** - Напоминание об актуализации урока

## Использование

### Создание уведомлений программно

```python
from apps.notifications.models import Notification

# Уведомление о DASCOIN
Notification.create_dascoin_notification(user, 150, "Вы получили 150 баллов!")

# Уведомление о назначении курса
Notification.create_course_assignment_notification(user, course)

# Уведомление об обновлении платформы
Notification.create_platform_update_notification(user, "Новая версия", "Описание обновления")
```

### Создание тестовых уведомлений

```bash
# Создать уведомления для всех пользователей
python manage.py create_test_notifications --all

# Создать уведомления для конкретного пользователя
python manage.py create_test_notifications --user username
```

### API endpoints

- `GET /notifications/` - список всех уведомлений
- `GET /notifications/<id>/` - детальная страница уведомления
- `POST /notifications/<id>/mark-read/` - отметить как прочитанное
- `POST /notifications/mark-all-read/` - отметить все как прочитанные
- `GET /notifications/count/` - количество непрочитанных (API)
- `GET /notifications/dropdown/` - данные для выпадающего списка (API)

## Автоматические уведомления

Система автоматически создает уведомления при:

1. **Изменении баллов DASCOIN** - через сигнал `post_save` для модели `Profile`
2. **Назначении траектории** - через сигнал `post_save` для модели `UserCourseTrajectory`

## Кастомизация

### Добавление нового типа уведомлений

1. Добавить новый тип в `NOTIFICATION_TYPES` в модели
2. Создать метод класса для создания уведомлений
3. Добавить обработку в шаблонах

### Изменение стилей

Стили находятся в `static/notifications/css/notifications.css` и поддерживают:
- Адаптивный дизайн
- Темную тему
- Анимации

## JavaScript функциональность

- Автоматическое обновление счетчика каждые 30 секунд
- AJAX загрузка выпадающего списка
- Отметка уведомлений как прочитанных без перезагрузки страницы
- Анимация пульсации для badge

## Безопасность

- Все views требуют аутентификации (`@login_required`)
- Пользователи могут видеть только свои уведомления
- CSRF защита для всех POST запросов
